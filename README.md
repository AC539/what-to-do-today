# 今天干嘛

拉一下拉杆，随机摇出今天的玩法和吃法。给"懒得决定"的人用。

## 直接打开

| 入口 | 说明 |
| --- | --- |
| [手机上玩](play.html) | 四个滚轮 + 摇完摊开一整天的行程卡，还能收灵感、管自己的池子 |
| [电脑版](desktop.html) | 大屏三滚轮 + 条件筛选，也能自己往内容池里加地方 |

> GitHub Pages 上的地址：`https://ac539.github.io/what-to-do-today/`

## 是什么

- **206 条成都本地的玩 / 吃地点**，公开信息整理：书店、展览、古镇、爬山、火锅、串串、日料……
- **摇出 上午玩 / 中午吃 / 下午玩 / 晚上吃**，然后自动摊开成"一整天的行程"：时间会串起来（午饭不早于 12:00、晚饭不早于 18:00，站与站之间留出路上时间），排到半夜会写"次日"。
- **自己往里加**：手机版顶上那个列表按钮里有两件事 —— 「灵感」可以从公开报道整理的清单里收、也可以粘贴一段话自动拆成条目；「池子」能搜、能标「常去」（更容易摇到）、能拉黑（不会再摇到），加进去的东西摇的时候真的会出现。
- **单文件 HTML，纯静态**：不联网、不注册、不上传任何数据。你自己的条目和摇出来的结果只存在你浏览器的 localStorage 里。

## 目录

```
index.html             入口页
play.html              手机版（构建产物）
desktop.html           电脑版（构建产物）
apple-touch-icon.png   被加到手机主屏幕时的图标
src/phone/             手机版源码：tpl.html + style.css + pool.js + ideas.js + app.js + build.py
src/                   电脑版源码：同上（另加条件筛选等），ideas.js 与手机版同一份
```

页面都能单独双击打开，`index.html` → `play.html` / `desktop.html` 之间的链接是相对路径，本地和线上都能跑。

## 自己改内容

内容池就是 `src/pool.js` / `src/phone/pool.js` 里的一个数组，一行一个地点：

```js
// 名称, 类型(p=玩 / e=吃), 子类, 区域, 价位1-3, 时长h, 标签, 贴士
["方所书店", "p","书店","锦江",2,2, "室内,安静,出片", "太古里负一层, 傍晚人少, 看完书直接上楼吃饭"],
```

改完在对应目录里跑一次构建，会把资源合回单文件：

```bash
python build.py            # 电脑版，产物在项目根目录
cd phone && python build.py  # 手机版，产物在 phone/
```

改完推上去就更新了线上页面：

```bash
git add -A && git commit -m "加了几个新地方"
git push
```

`github.com` 在部分网络下直连不稳（443 会被重置）。推不上去时，本地另有一个走 `api.github.com` 的部署脚本可以代替 push：
它先逐个比对 blob / tree / commit 的 sha，全部一致才更新分支，所以线上和本地永远是同一个提交（这种脚本涉及令牌，不放进仓库）。
